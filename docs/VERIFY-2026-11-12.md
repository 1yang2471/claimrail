# 真浏览器验证（2026-11-12）：web 命令 + 报告落盘链

补上 0.2.6 报告里"没验证到的"第一条：`web` 命令的报告 UX 此前只审过结构，没跑真浏览器。本轮用真 Chromium 端到端跑了一遍，并**故意构造五类缺陷**对照页，验证判红/判绿/退出码都对得上。

## 环境

- 真 Chromium（本机 `playwright` devDependency，`chromium.launch()` 成功）。
- 对照页 `_tmp/web-verify-20261112/page.html`（本地 `node http` 服务），五类缺陷各一处：低对比度文字、18px 触摸目标、`outline:none` 按钮、横向溢出滚动容器、固定底栏。

## 结果 A：五项检查与退出码

```
390x700 · 容器 1 · 文本 12 · 可交互 4（真实 Tab 探到 5）· 固定条 1
  ✓ scrollbar-clears-text：已核 1 个滚动区，无压在内容上的条带
  ✗ touch-targets-ok：4 个可点控件短边不足 44px（button.tiny:nth(1..3) 等 4 处）
  ✗ contrast-ok：4/12 处正文对比度不足 4.5:1，最低 1.66
  ✗ focus-visible-ok：1 个可聚焦元素聚焦时看不出变化：#nb
  ✓ bottom-not-covered：已核 1 个固定元素
  可引用：{ "kind": "render", "ref": ".claimrail/shots/….png", "asserts": ["scrollbar-clears-text","bottom-not-covered"] }
...
退出码 1：有检查项判红
```

两视口结论一致；判红的正好是埋的三类（触摸目标、对比度、焦点），判绿的是没埋的两类；退出码 1。**五项检查在真浏览器里跑通。**

## 结果 B：证据闭环

- 把 `web` 输出的 `可引用` 行原样喂进台账（`asserts` 只含判绿项），截图 mtime 晚于代码 → `check` 退出 0，理由"1 条分叉均有可回验证据"。**闭环成立。**
- 台账里多声称一个判红项（`contrast-ok`）→ `check` 判未验证，原话「contrast-ok 判红：4/12 处…最低 1.66」。**没有把红的说成绿的。**

## 结果 C：落盘链的防伪边界（三条）

| 攻击 | 结果 |
| --- | --- |
| 手写报告（删掉 `shot_sha256`） | 拦：「报告没有绑定截图（缺 shot_sha256）」 |
| 截图换掉（PNG 加一个字节） | 拦：「截图与报告不是同一次采集（哈希对不上：报告 a5a8bada…，截图 e220f574…）」 |
| 截图比代码旧 | 拦：「截图比代码旧」 |
| **直接改报告 JSON**（把 `contrast-ok` 的 `false` 手改成 `true`，截图不动） | **放行** —— 报告内容本身无完整性保护 |

第四条是 `docs/BOUNDARIES.md` 写明的「伪造证据不在防御范围」（威胁模型：不合作但不攻击）。`shot_sha256` 绑的是报告↔截图，不绑报告自身内容；能改报告 JSON 的模型同样能改截图。要挡这一层只能从像素重算（对比度可部分重算，几何项不可），目前不做，已在 BOUNDARIES 与 AGENTS 规则表里点名，别把 `shot_sha256` 当报告完整性。

## 顺带修的真 bug

验证过程中发现 `HOST_NOISE`（宿主噪音）只在 `untracked` 一路生效，`diff ranges` 与 `treeHash`/副作用扫描读的 diff 文本两路照漏：被跟踪过的 `.mimosa` 文件被宿主改写后，会混进"改动面"、或让 hook 误判 stale。已下沉到 `changedLines` 源头 + 新增 `stripHostNoiseDiff`，并**收窄名单为只收实测过的 `.mimosa`**（`.claude`/`.cursor` 常被用户有意跟踪为配置，收了会把真活藏起来）。`test/host-noise.test.mjs` 三条钉住（含 `.claude` 仍算工作改动的反向用例），两处守卫变异验证：拆 → 红，还原 → 绿。

## 没验证到的

- 报告的**视觉**呈现（人肉看截图好不好看）没做图像美学评估，只核了数值判定；截图人眼复核在此前对比度轮次做过。
- 私有产品页 / 需真实凭据的登录闭环仍未跑（本地登录门与 saucedemo 演示账号此前已跑）。
- `precedent`/`web` 两档的真网络回访依赖 `FK_NET=1`，本次默认关，用的是离线路径。
