## P1/P2 修复清单（每条都先实测复现再改）

- **空 baseline 永不修复**：init 跑在没有提交的仓库里留下空文件，commit 后模板台账照样退出 0。
  修：init 补写（`readBaseline ?? writeBaseline`）+ check fail-closed（模板不许认证看不见工作区的交付）。
- **门 fail-open 三处**：没有 baseline / git 读不出 / unknown 时模板台账照样认证交付。
  修：`workVisible` 判定直接拦；`none`（确实不是仓库）保持显式降级放行（BOUNDARIES 写明的模式）。
- **子目录路径基准错位**：git diff 键是仓库根相对，文件读取按 cwd 拼接 → "先干后证"在子目录里漏拦
  （cwd 相对 ref 躲过变更比对）、根相对 ref 反而读不到文件。修：check/hook/init/web 都以
  `gitToplevel` 为基准；`--ledger` 认绝对路径；`web --out` 必须在仓库内（仓库外写不出可回验 ref）。
- **截断守卫漏两类**：`focusVisibleOk` 不查 interactive 截断、`bottomNotCovered` 不查
  scrollContainers 截断——截断的报告出 true 还能被 render 证据引用成"已验证"。
- **截图排在 Tab 焦点探测之后**：Tab 会滚动页面（真站实测一次 0→911→1532），像素采样拿旧坐标读新图。
  修：截图先行；调用顺序测试钉住 evaluate → screenshot → focusProbe。
- **stale 误伤协议文件**：只改已跟踪的 AGENTS.md 时拦一句"这次改了 0 个文件"。修：touched 为 0 不进 stale。
- **render 新鲜度对删除失明**：删文件只更新父目录 mtime，"截图之后删了文件"仍算新的。
  修：被删路径父目录 mtime 并入 `newestTrackedMtime`。
- **schema 与 verify 错位**：memory 档 schema 放行（没要求 asserts）、verify 却必挂——结构校验通过、
  整轮跑完才失败。修：`ASSERTS_REQUIRED` 含 memory。
- **段中 `..` 逃出仓库**：`a/../../etc/x.png` 不以 ../ 开头，schema 放行、join 后越过仓库根。
  修：schema 三层入口（evidence.ref / target.file / options[].target.file）拒收 + check 运行时
  `safeResolve` 兜底（resolve 后与仓库根比前缀，越界交 null → 证据失败）。
- **绝对路径被 join 拼坏**：`--ledger`/`--out` 给绝对路径时拼成 `<cwd>\D:\x`（ENOENT 或静默找不到）。
  修：台账与输出目录 resolve 语义。
- **CLI 入口测试盲区**：hook 的文本走 stderr，`execFileSync` 只在失败时给 stderr——"放行但留原因"
  的分支在旧 runCli 下测不到输出。修：runCli 换 `spawnSync`，stdout+stderr 都收。
