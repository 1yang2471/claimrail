# UX 审查（2026-11-12）：效果 + 用户体验

审查角色：UX 研究员 × 技术文档工程师 × 代码审查员。方法：真 CLI 冷启动模拟（两个临时仓库）+ trouble-maker 对抗审查全部文本面（README 双语 / SKILL.md / AGENTS.md / help / check 输出 / PRD）+ 每条发现逐条复现或对到代码行。原始发现 20 条（1 阻断 + 10 应当修 + 9 小问题）+ 冷启动报告 3 条独立发现，全部已修（0.2.6）。

## 阻断

1. **照 SKILL.md 做会把登录凭据提交进 git**。协议教的 `--state .claimrail/storage.json` 不在 init 的 .gitignore 清单里，storageState 存的是 cookie。修：init 清单补 `.claimrail/storage.json`，数据去向通知点名登录态（`test/init-files.test.mjs` 钉住）。

## 应当修（10 条全修）

2. **宿主插件噪音触发假拦截**：`.mimosa/hook-state/*.json`（ZCode 插件每次 Bash 丢一个）计入"工作区有改动"，能单独触发 stale 假警报、抢在正文对撞之前。修：`observe/git.mjs` 的 `HOST_NOISE`（六个实测过的宿主目录），未跟踪文件与 mtime 两处过滤；变异验证拆守卫→红 2。`test/undeclared.test.mjs`、`test/hook.test.mjs`。
3. **"规则四"死胡同**：标签在全部对外文档零定义；"按候选配 target"的合法写法（`options: [{label, target}]`）全文档无示例；"未知字段"报错说"只许申报下面这些字段"却不列字段。修：输出头改"候选代价未算出 · 每个候选配 target 才能算"，`metrics.rule4NotEnabled` → `optionsCostUnavailable`，schema 报错真列字段清单，SKILL.md 双语补 `{label, target}` 写法与本地三档形状（memory 档 ref 只认 `log#n` 这类字段形状此前零文档）。
4. **通过态不列改动清单**：用户想知道"门看见了什么"只能自费实验。修：通过态也打"改动面 N 个文件"行，`--json` 给 `changedFiles`；审计项不再重复列文件。
5. **模板 task_class 硬编码 ui-new**：docs/refactor 任务被 ui-new 规则静默管着。修：模板占位行扩成 task_class 提示；`isTemplateReason` 兼容 0.2.5 旧占位串（老仓库被重新序列化的模板不静默漏拦，`test/undeclared.test.mjs` 钉住）。
6. **【开工前 N 条】出现在交付时**：与 README"门拦交付不拦动工"自相矛盾。修：改【交付被拦 · N 条需你定】。
7. **stale 文本与 SKILL.md"不许改措辞"打架**。修：改"把台账改成针对这次改动的申报——结论可以一样，理由必须是这次的理由"。
8. **--json 在 schema 拒收路径是散文**。修：`check` 返回结构化 `data.errors`；变异验证拆附加→红 1。`test/hook.test.mjs`。
9. **本地三档证据形状零文档**（memory ref 只认 `log#n` 等）。修：SKILL.md 第三节给三档各一行最小形状（双语）。
10. **指路段只给命令无 fallback**。修：AGENTS 指路段补"命令不存在时：npm link 或 node 直接跑 src/cli.mjs"。
11. **"需打断 N 次"用而不释**。修：改"需你定 N 条"。
