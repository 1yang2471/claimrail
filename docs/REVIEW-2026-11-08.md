## 这一轮修了什么

trouble-maker 与 tester 各做了一轮对抗式审查（独立子代理、并行、互不通气），共报 6 个阻断项 + 7 个应当修 + 5 个小问题。**全部已修并逐条变异验证**，没有一条是"文档说改了"：

- **假绿（钩子）**：一句否认能同时短路两道防线——"本次交付没有任何未验证的事项"里含"未验证"三字，声明识别（关键词存在性）返回真 → 直接放行，连"宣称全部核实"都没查。改成：声明优先，但**全称否定不算声明**（`VOID` 守卫）；再加一条"声明优先"用例钉住顺序。
- **假绿（截断）**：`truncated()` 只判 texts 与 interactive，滚动容器与固定元素被截断时仍报"已核 60 个滚动区"。页面上固定元素超过 40 个很常见，被丢掉的那条压内容永远查不到。四类采集现在一个都不漏。
- **可绕过（代价）**：target 由模型填，指向不存在的路径/符号时"0 处引用"是假零，而 fanIn 是便宜/贵的输入之一 → 判 null（按 high）。文件级 fan-in 也要认 `./helper.mjs` 这种相对写法（拿仓库相对路径精确匹配会把三处 import 算成 0）。
- **崩溃**：台账 asserts 里写不存在的检查项名 → `c.ok` TypeError → 掉进 check 的兜底 catch，用户看到"检查没跑完"。改成报"未知检查项"。
- **报告不实**：非 git 降级横幅说"repo 证据无法回验"——其实读得了文件与行，丢的是先干后证；文案改成点名丢掉哪一条。git 本身用不了也不再被说成"不是仓库"。
- **退出码说谎**：`claimrail web` 五项全未判时退出 0（CI 会当成检查通过）。改成 1，并给 web 命令补了注入缝与第一批测试（这个命令以前一行测试都没有）。
- **顺手修掉的**：图片背景假绿（10px 棋盘曾报 6.80 合格，实际白格上只有 1.67）；透明文字假红；init 往目标仓库写 `*.png` 通配（会静默排除用户仓库里的真实图片）；`.gitignore` 与 pre-commit 里改名后遗留的 `.forklight` 死规则（导致 bench 夹具新截图会被 `*.png` 吃掉）；真实测量产物 `.claimrail/shots/*.report.json` 已从索引里移除。
- **测试自身的漏洞**：CLI 用例曾跑在真实仓库上（开发者一改 `src/cost.mjs` 就假红）→ 改成自造临时仓库；"证据查得到"那条断言太弱 → 补"未验证 0 条 / 均有可回验证据"；whyUnknown 三条原因逐条钉住；浏览器层在 Playwright 坏安装时会整层静默跳过（假绿）→ 现在会响。
- **发布卫生**：`src/cli.mjs` 20370 字节、`test/cli.test.mjs` 21066 字节，都超过提交钩子的 20000 字节上限 → 按功能拆分（`src/commands/check.mjs`、`test/hook.test.mjs`、`test/helpers.mjs`），不调阈值、不 `--no-verify`。`src/bench.mjs` 是开发工具且协作者不在发布包里 → 搬到 `bench/runner.mjs`，不再进 npm 包。
